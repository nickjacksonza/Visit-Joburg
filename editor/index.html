Events editor set-up

  1. On GitHub, create a fine-grained token for this repository only, with Contents: Read and write, and Actions: Read-only.
  2. Paste it here and choose a password of at least 16 characters (four or five random words work well).
  3. The page encrypts the token with the password and saves only the encrypted copy to editor/sealed.json. The token itself is never stored.
