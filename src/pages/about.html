About

About Visit Joburg

{{ name }} is an independent guide to Johannesburg for visitors. We want to help people see more of the city, with clear advice in plain words.

What We Include

We list places we would send a friend to on their first visit. Nobody pays to be included. When we link to a business, it is because we think it is useful, and we do not earn a fee for it.

Keeping It Accurate

Opening hours, prices and transport change often, so we do not list them. Each listing links to a map, and we ask you to check details with the place itself before you go. Each page shows the date we last reviewed it.

Not an Official Body

{{ name }} is not linked to the City of Johannesburg, the Gauteng Tourism Authority or South African Tourism.

Suggest a Change

If something is wrong or missing, tell us. We read every message.
